# 모바일/웹서비스 프로젝트 공통평가 01

Django 서버와 Android 앱을 연동해 사진과 글을 게시하고 조회하는 과제입니다.

## 구현 내용

- Django 기반 사진 블로그와 게시물 API 구현
- Android 앱에서 제목·내용·사진을 입력해 게시물 업로드
- 서버의 게시물과 사진을 앱으로 불러오는 동기화 기능
- PythonAnywhere 배포 및 실제 휴대폰에서 서버 연동 확인

추가 편의 기능으로 게시물 상세보기, 제목·본문 검색, 최신순·오래된순 정렬, 게시물 공유, 사진 모아보기를 구현했습니다.

## 수행 결과

로컬 서버와 클라우드 서버에서 게시물 업로드와 동기화를 확인했습니다. 항목별 구현 내용과 동작 화면은 수행 결과 보고서에 정리했습니다.

배포 주소: https://garamkang.pythonanywhere.com/
